<objective>
Scaffold the Vite + React TypeScript frontend, install and configure Tailwind CSS and Framer Motion for 3D perspective animations, implement the API client with JWT injection, configure the Auth Context, build the responsive navigation bar, and build the reusable 3D tilt card component.
</objective>

<threat_model>
ASVS Level 1:
- Token security: JWT stored securely in localStorage, automatically attached via Bearer authorization headers; cleared on HTTP 401.
- XSS prevention: Clean JSX interpolation without dangerous inner HTML.
- Client validation: Zod/regex validation for auth fields before network transmission.
</threat_model>
