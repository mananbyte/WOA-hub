<objective>
Scaffold the Vite + React TypeScript frontend application, configure Tailwind CSS with the dark aviation theme, establish the API client with automatic JWT bearer token injection, implement the authentication context and modal (signup/login), and build the responsive navigation layout.
</objective>

<threat_model>
ASVS Level 1:
- Token storage: JWT stored in localStorage or memory; auth client automatically attaches `Authorization: Bearer <token>` to protected endpoints.
- XSS prevention: React's JSX automatically escapes strings; no `dangerouslySetInnerHTML`.
- Form validation: Client-side validation for email, password length, and Discord username format before submission.
</threat_model>

    - Configure `web/tailwind.config.js` with dark aerospace theme colors (`#0B0F19`, `#111827`, `#1F2937`, sky-cyan `#38BDF8`, amber `#F59E0B`).
