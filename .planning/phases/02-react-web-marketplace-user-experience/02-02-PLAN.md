<objective>
Build the interactive marketplace board with real-time filtering (airport, aircraft class, cargo/pax, type), search, contract creation modal, contract detail modal with bilateral status history, and the player dashboard with 1-click status actions ("Mark Dispatched", "Confirm Accepted").
</objective>

<threat_model>
ASVS Level 1:
- State action authorization: UI action buttons (dispatch, accept, approve, cancel) must reflect the user's role (creator vs claimant) and only trigger valid transitions; backend enforces row-level permissions.
- Debounced search: Input sanitization prevents regex or injection vulnerabilities.
</threat_model>

<tasks>

  <action>

    - `FilterBar.tsx`:

      - Airport search / filter dropdown (PRG, INN, BRI, SAN, IAD, MCT, NGO, LEJ, SXM, HKG).
      - Aircraft class pills: Multi-select A, B, C, D, E, F.
      - Cargo vs Passenger toggle switch.
      - Search input with debounced keyword filtering.
    - `ContractCard.tsx`:
      - Visual route display: Origin Airport Code -> Arrow -> Destination Airport Code.
      - Badges: Aircraft Class (e.g. "Class D"), Cargo/Pax indicator, Contract Type pill.
      - Creator profile summary: Discord handle, WoA ID, reputation rating score.
      - Expiration countdown timer (e.g., "Expires in 8h").
      - "Claim Connection" or "View Details" button.
