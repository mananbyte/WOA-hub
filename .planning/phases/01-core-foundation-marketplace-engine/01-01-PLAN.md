<objective>
Initialize the TypeScript/Node.js project environment, configure Drizzle ORM with PostgreSQL, define the complete core database schema (users, airports, listings, listing_claims, status_events) including partial unique indexes for claim concurrency, seed WoA airport codes, and verify the schema push.
</objective>

<threat_model>
ASVS Level 1:
- Sensitive credentials: Database connection credentials must use environment variables loaded via `dotenv`, never committed in source control.
- SQL Injection: Drizzle ORM parameterizes all queries; no raw string concatenation in SQL queries.
</threat_model>

<tasks>
<task id="T1">
  <action>
    Initialize the Node.js project and install core backend dependencies and dev tools.
    - Create `package.json` with scripts: `dev`, `build`, `db:generate`, `db:push`, `db:seed`.
    - Create `tsconfig.json` configured for Node.js 22 LTS with ES2022/ESNext modules and strict typechecking.
    - Create `.env.example` defining `DATABASE_URL`, `JWT_SECRET`, and `PORT`.
    - Install `express`, `pg`, `drizzle-orm`, `zod`, `jsonwebtoken`, `bcryptjs`, `dotenv`, `cors`, `pino`.
    - Install dev dependencies `typescript`, `@types/node`, `@types/express`, `@types/pg`, `@types/jsonwebtoken`, `@types/bcryptjs`, `@types/cors`, `tsx`, `drizzle-kit`.
  </action>
  <verify>
    node -e "require('./package.json'); console.log('package.json valid')" && npx tsc --version
  </verify>
</task>

<task id="T2">
  <action>
    Configure Drizzle ORM and write the complete relational schema in `src/db/schema.ts` and database client in `src/db/index.ts`.
    - Create `drizzle.config.ts` targeting PostgreSQL with `src/db/schema.ts`.
    - Define `users` table: `id` (uuid defaultRandom), `email` (varchar unique), `password_hash` (varchar), `discord_username` (varchar), `woa_player_id` (varchar nullable), `reputation_score` (numeric default 5.00), timestamps.
    - Define `airports` table: `code` (varchar(4) primary key), `name` (varchar), `region` (varchar).
    - Define `listings` table: `id` (uuid), `creator_id` (references users), `contract_type` (enum 'outgoing', 'incoming'), `status` (enum 'open', 'claimed', 'in_progress', 'completed', 'cancelled'), `aircraft_class` (enum 'A', 'B', 'C', 'D', 'E', 'F'), `is_cargo` (boolean), `origin_airport` (references airports), `destination_airport` (references airports), `notes` (text), `expires_at` (timestamp), timestamps.
    - Define `listing_claims` table: `id` (uuid), `listing_id` (references listings), `claimant_id` (references users), `status` (enum 'pending', 'accepted', 'rejected', 'cancelled'), timestamps.
    - Add partial unique index on `listing_claims(listing_id)` where `status IN ('pending', 'accepted')` to strictly enforce single active claim concurrency at the database level.
    - Define `status_events` audit table: `id` (uuid), `listing_id` (references listings), `actor_id` (references users), `from_status` (varchar), `to_status` (varchar), `event_type` (varchar), `notes` (text), `created_at` (timestamp).
  </action>
  <verify>
    npx tsc --noEmit
  </verify>
</task>

  </verify>

</tasks>
