<objective>
Implement the audience-scoped query engine for contracts (`public` vs `alliance_only`), deploy the `pg-boss` background worker for automated listing expiration (24h/4h) and private-to-public escalation timers, and construct the dedicated alliance web pages (`/alliances` directory, `/alliances/:slug` public lounge, and `/alliances/:slug/deck` private operations command deck with interactive route matrix).
</objective>

<threat_model>
ASVS Level 1:
- Scoped data access: Database queries for `alliance_only` listings strictly filter by caller alliance membership; non-members receive zero rows even if they guess listing UUIDs.
- Background worker isolation: `pg-boss` jobs run with idempotent status guards ensuring listings are only escalated or expired once.
- Safe client routing: Public and private views validate permissions before displaying internal flight decks.
</threat_model>

<tasks>
<task id="T1">
  <action>
    Install `pg-boss` and build the background worker in `src/jobs/worker.ts`:
    - `npm install pg-boss @types/pg-boss`
    - Initialize PgBoss instance using PostgreSQL connection (`DATABASE_URL`).
    - Handlers:
      - `escalate-alliance-listing`: Inspects listing; if still `status = 'open'` and `visibility = 'alliance_only'`, updates `visibility = 'public'` and records audit event `escalated_public`.
      - `cleanup-stale-listings`: Cron running every 15 minutes checking `expires_at <= NOW() AND status = 'open'`, marking status `expired`. Also cancels unapproved claims older than 4 hours.
    - Start worker on server boot in `src/index.ts`.
  </action>

  </verify>
</task>
