<objective>
Implement the Discord-style Alliance Guest Contract Request protocol, expand the playable airport registry to all 18 official World of Airports hubs, add the renewal flag and `partially_dispatched` contract state, and enforce direction-aware smart airport filtering (Incoming = Destination airport filter; Outgoing = Origin airport filter).
</objective>

<threat_model>
ASVS Level 1:
- Directional filter security: SQL parameterized equality on airport codes prevents SQL injection while honoring contract directionality.
- Scoped guest requests: Guests can only create incoming requests for alliances they are registered in; non-members cannot query private guest queues.
- State progression integrity: Only authorized flight senders can mark `partially_dispatched` or `dispatched`.
</threat_model>
